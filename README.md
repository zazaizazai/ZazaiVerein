# Vereinswebsite MVP (Next.js App Router)

Kleine, seroese Vereinswebsite fuer den schnellen Launch auf Vercel.

## Enthaltene Seiten

- `/`
- `/ueber-uns`
- `/mitmachen`
- `/kontakt`
- `/impressum`
- `/datenschutz`

## Lokal starten

```bash
npm install
npm run dev
```

Dann im Browser: `http://localhost:3000`

## Build pruefen

```bash
npm run build
npm run start
```

## Deployment auf Vercel

1. Repository mit Vercel verbinden
2. Framework: **Next.js** (wird automatisch erkannt)
3. Build Command: `npm run build`
4. Output: Standard (Next.js)
5. Deploy
