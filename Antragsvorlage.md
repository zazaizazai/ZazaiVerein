# WhatsApp-Abstimmungsfrage (Vorlage)

## Kurzvorlage (zum Kopieren)

Hallo zusammen,  
es wird folgende Frage zur Abstimmung gestellt:

"[Frage]"

Bitte um Abstimmung bis [Datum/Uhrzeit].  
Antwort mit: **Ja / Nein / Enthaltung**.

Danke.

---

## Beispiel: Internetseite

Hallo zusammen,  
es wird folgende Frage zur Abstimmung gestellt:

"Soll der Verein eine offizielle Internetseite einrichten und betreiben?"

Bitte um Abstimmung bis [Datum/Uhrzeit].  
Antwort mit: **Ja / Nein / Enthaltung**.

Danke.
